# DREAVON 1.0.0 — uso pessoal no Windows

Primeira versão do DREAVON: o painel com chat multi-IA, música, rede, sistema, dispositivos, lembretes, clima, notícias e calendário, agora no **Windows**, numa janela própria com ícone na bandeja.

O DREAVON é uma adaptação do [Plasdria](https://github.com/PietroAlexandria/Plasdria) (© Pietro Alexandria, MIT), um widget para o KDE Plasma 6.

> **Sem binários anexados.** Esta versão é para uso pessoal: não há instalador nem assinatura. O app é compilado a partir do código e abre pelo `qml.exe` assinado do Qt.

## Destaques
- **Janela própria com bandeja:** fecha para a bandeja e tem atalho global (`Ctrl+Shift+Alt+D`, configurável).
- **Chat multi-IA:** Claude, Antigravity e APIs compatíveis com OpenAI, com os CLIs executados sem passar pelo `cmd.exe`.
- **Música:** controle de mídia do Windows (Spotify, navegadores e outros players), com capa, posição e controles.
- **Rede:** tráfego só das placas físicas, IP, tipo, nome e sinal do Wi-Fi, latência e modo offline.
- **Sistema:** CPU, memória, swap, disco, GPU, bateria e temperatura do SSD.
- **Dispositivos:** aparelhos USB e Bluetooth com bateria, inclusive o mouse Logitech pelo receptor.
- **Lembretes com alarme:** notificação com o nome "DREAVON", alarmes agrupados e indicador no cartão para não perder nada com o Não Perturbe.
- **Leve em repouso:** ~1% de um núcleo com a janela oculta e 2–10% com ela aberta.
- **Configurações > Sobre:** versão, créditos e licenças.

## Como usar
Requisitos: Windows 10/11, Qt 6 (MSVC 64 bits), Visual Studio Build Tools com C++, CMake e Ninja.

```powershell
git clone https://github.com/Pedro-Andreotti/DREAVON.git
cd DREAVON
.\build-windows.ps1             # compila
.\tools\install-local.ps1       # atalho "DREAVON" no Menu Iniciar (opcional: -IniciarComWindows)
```
Depois, abra pelo Menu Iniciar. Passo a passo e solução de problemas: [docs/abrir-no-windows.md](https://github.com/Pedro-Andreotti/DREAVON/blob/v1.0.0/docs/abrir-no-windows.md).

## Limitações conhecidas
- **Temperatura da CPU:** indisponível no Windows (não há fonte nativa sem administrador).
- **Bateria do mouse Logitech:** leitura instável (~45% dos ciclos); o cartão segura o último valor por até 10 min.
- **Bateria do fone Bluetooth e de aparelhos BLE:** ainda não aparece.
- **Kirigami:** substituído por um shim mínimo só do Windows.
- **Sem instalador e sem assinatura:** o `dreavon.exe` seria bloqueado pelo Controle Inteligente de Aplicativos; por isso o app abre pelo `qml.exe` do Qt.
- **Linux:** não testado nesta versão.
