# Ícones Breeze (subconjunto)

Ícones do tema [Breeze](https://invent.kde.org/frameworks/breeze-icons), do KDE, copiados sem alterações
só com os nomes usados pelo DREAVON. Licença: LGPL-3.0-or-later (ver `COPYING-ICONS`).
Copyright (C) 2014 Uri Herrera e outros.

Para incluir um ícone novo, copie o SVG de `icons/<categoria>/22/<nome>.svg` do repositório do Breeze
para esta pasta e acrescente o nome em `../IconNames.js`.
