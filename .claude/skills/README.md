# Skills do projeto (Claude Code)

Cópias das skills que o autor usa globalmente, para que qualquer sessão do Claude Code neste
repositório (VS Code, nuvem, outra máquina) tenha as mesmas. Nenhuma foi alterada.

| Skill | Autor | Origem | Licença |
| --- | --- | --- | --- |
| `design-system` | Albert Zhang | https://github.com/albertzhangz10/design-system-skill | MIT (`design-system/LICENSE`) |
| `task-observer` | Eoghan Henn e colaboradores | https://github.com/rebelytics/one-skill-to-rule-them-all (versão 3.7.0) | CC BY 4.0 (`task-observer/LICENSE.txt`) |

As skills sincronizadas da conta do Claude (docx, pdf, pptx, xlsx etc.) não estão aqui: são da Anthropic
e já aparecem em qualquer sessão da mesma conta.

Para atualizar uma skill, copie a versão nova da origem para esta pasta, sem mudar o conteúdo.
